# Kashi Nirmal Heights Landing Page

Premium one-page React + Vite landing page built from the supplied Kashi Nirmal Heights brochure.

## Source / asset rule
- Brochure imagery is used as the visual source.
- No AI-generated replacement imagery is used.
- Artistic impressions / stock imagery are labelled where applicable.
- Internal brokerage, channel-partner incentives and payout information are excluded.
- Pricing is intentionally excluded until separately verified for customer-facing use.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
